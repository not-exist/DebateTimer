# 辩论计时器（DebateTimer）

跨平台（Windows / macOS / Linux）的辩论赛计时器，面向学校多媒体教室：单屏全屏、浅色简洁界面、内置多套辩论赛流程并支持自定义，提示音用 Web Audio 实时合成（不依赖任何音频文件）。

## 功能

- **单屏全屏**：一个界面给全场看，辩题、当前环节、巨型计时数字、进度条一屏显示；鼠标静止几秒后底部控制条自动淡出，投影更干净。
- **内置赛制**：四辩制（大学常见）、新加坡模式（四人制）、三人制（中学）、奥瑞冈制（五·四·四）、四辩制精简版、空白自定义。
- **自定义赛制**：环节可增删、上下移，可改名称、时长、提示点；支持导出 / 导入 JSON，方便拷给其他老师。改内置模板时会自动另存为自定义副本，内置数据不会被改坏。
- **辩题与队名随时改**：点击顶部文字即可编辑（或按 `T`）。
- **现场提示**：到点前响铃 + 屏幕横幅（如"还剩 30 秒"），到点响钟声并变红；支持一 / 两 / 三声（奥瑞冈需要三级铃）。
- **三种计时模式**：单边倒计时；双边分离计时（自由辩论，一方落座即起另一方）；双计数分计（盘问的提问 / 回答各一块表）。
- **计时准确**：剩余时间按绝对截止时间戳计算，不累积漂移；提示点预算成绝对时间戳，掉帧或系统休眠后一次性补触发，不会漏报。
- **快捷键完整**：见下方表格；改辩题 / 改时长时输入框内自动屏蔽单键快捷键，不会误启停计时。
- **退出入口**：控制条与赛制面板各有一个「退出」按钮，点击后二次确认，避免现场误触中断比赛。

## 使用方法

### 跑一场比赛

1. 打开应用（默认全屏，按 `F11` 或 `F` 可退出 / 回到全屏）。
2. 点顶部辩题改成今天的题目，点「正方 / 反方」可改队名。
3. 按「赛制」选择流程；需要调整时长就直接在面板里改。
4. 按 `空格` 开始计时，`空格` 暂停，`Enter` 进入下一环节，`R` 重置当前环节。
5. 自由辩论环节按 `Tab` 切换发言方，两块计时器各自独立。
6. 结束后点「退出」（二次确认）关闭应用。

### 快捷键

| 键 | 动作 |
|---|---|
| 空格 | 开始 / 暂停当前环节 |
| Enter / → | 下一环节 |
| Backspace / ← | 上一环节 |
| R | 重置当前环节 |
| Tab | 自由辩论切换发言方 |
| + / − | 当前环节 ±10 秒（Shift 为 ±60 秒） |
| 1–9 | 跳到第 N 个环节 |
| T | 修改辩题 |
| F11 / F | 全屏切换 |
| H | 快捷键帮助 |
| Esc | 关闭弹窗 / 退出编辑 |

### 关于赛制时长

辩论赛**没有全国统一的计时标准**（"剩 30 秒提示"只是行业惯例），各校差异很大，所以内置时长都可以改。来源如下，供核对：

- 四辩制（大学）· 三人制（中学）：各校公开的赛制文件
- 新加坡模式：https://wikis.pro/新加坡制
- 奥瑞冈五·四·四：https://zhuanlan.zhihu.com/p/645628336
- 四辩制精简版：来源为搜索摘要，原始 .doc 未抓取成功，**数字待现场复核**

### 从源码运行 / 打包

```bash
npm install
npm run tauri dev     # 启动桌面应用（首次会编译 Rust，较慢）
npm test              # 运行 core 层单测
npm run check         # 类型检查
npm run tauri build   # 打包
```

通常在哪个系统上构建就产出哪个系统的安装包（交叉编译需要额外配置 CI）。Windows 目标机器需 WebView2（Win10 1803+ 系统自带，否则需随包安装运行时）。字体已本地打包，教室无网络也能正常显示。
